# Business model - 1 page (jury)

## Grille tarifaire (Fc)

| Flux | Qui paie | Tarif |
|---|---|---|
| **Transfert interne** (wallet → wallet) | — | **0 Fc** (levier croissance) |
| **Abo AVEC** | Chaque groupe | **1 000 Fc / mois** |
| **Dépôt / retrait MoMo** | Utilisateur | **3,5 %** |
| **Licence ONG / facilitateur** | Chaque ONG qui suit ses AVEC | **10 000 Fc / mois** |
| **Marché** | Acheteur | **1 %** sur chaque transaction |

Pas de float bancaire : on n’est pas banque — marge logicielle + commissions rails.

## Qui paie quoi

| Segment | Offre | Prix |
|---|---|---|
| Groupe AVEC | OS parts · caisse · votes · Passport | 1 000 Fc / mois |
| ONG / facilitateur | Multi-groupes · alertes · export PV | 10 000 Fc / mois |
| Membre (wallet) | Dépôt / retrait Fc | 3,5 % |
| Acheteur Marché | Escrow communauté | 1 % |
| Institution (FOGEC, MFI) | Lecture Passport (consentement) | API / partenariat |

## Pourquoi c’est une grande économie

1. **Récurrent** — abo AVEC + licences ONG (SaaS prévisible)  
2. **Volume** — 3,5 % sur chaque entrée/sortie MoMo (corridors réels)  
3. **GMV Marché** — 1 % acheteur sur le commerce communautaire  
4. **Viralité gratuite** — transferts 0 Fc → plus d’utilisateurs → plus de dépôt/retrait/Marché  
5. **Canal B2B2C** — 1 ONG paie 10 000 Fc et amène N AVEC à 1 000 Fc

## Scénario illustratif (mois)

Hypothèse pilote mature (ordre de grandeur jury) :

| Ligne | Calcul | Recettes / mois |
|---|---|---|
| Abo AVEC | 100 groupes × 1 000 Fc | **100 000 Fc** |
| Licences ONG | 5 ONG × 10 000 Fc | **50 000 Fc** |
| MoMo 3,5 % | Volume 50 M Fc × 3,5 % | **1 750 000 Fc** |
| Marché 1 % | GMV 20 M Fc × 1 % | **200 000 Fc** |
| Transferts internes | illimité × 0 Fc | **0 Fc** (acquisition) |
| **Total** | | **≈ 2,1 M Fc / mois** |

→ Le moteur n’est pas l’abo seul : c’est **abo + ONG + volume MoMo + GMV Marché**, avec les transferts gratuits comme carburant d’usage.
