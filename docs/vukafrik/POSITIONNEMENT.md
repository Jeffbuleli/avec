# Positionnement e-AVEC vs tontines digitales

Sources d’inspiration concurrentes : [Djangui](https://djangui.net/), Likelemba / Maman Tontine, KIKA.  
Soubassement méthodologique : guides AVEC/VSLA ([ICI Cocoa](https://www.cocoainitiative.org/fr/centre-de-ressources/ressources/guide-dimplementation-associations-villageoises-depargne-et-de), [Access Agriculture](https://www.accessagriculture.org/fr/associations-villageoises-depargne-et-de-credit), FAO Tanganyika, Fondation RAJA, [GBV Responders AVEC guide](https://www.gbvresponders.org/wp-content/uploads/2019/08/004_AVEC_Guide-Facilitateur_Francais.pdf), [World Bank / GBV](https://blogs.worldbank.org/fr/nasikiliza/village-savings-and-loans-associations-support-gender-based-violence-gbv-survivors-afe-0324)).

## Ce que font les apps tontine

- Tours / cagnottes / likelemba
- Rappels, MoMo, parfois coach IA
- Mode déclaratif (l’app ne détient pas les fonds)
- Grand public & diaspora

## Ce qu’e-AVEC revendique (révolutionnaire)

| Pilier AVEC (méthodologie) | e-AVEC |
|---|---|
| Épargne cumulative + crédit interne | Parts 1-5, prêts, cycle, clôture |
| Fonds social | Solidarité par réunion |
| Gouvernance collective | Votes crédits / règles |
| Facilitateur / ONG | Portefeuille + alertes intégrité |
| Lien au formel | Passport + consentement |
| Ancrage RDC | Fc · MoMo · BCC disclaimer |

**Phrase jury :**  
> Les autres digitalisent la *tontine*. Nous digitalisons la *méthodologie AVEC* - pour que la caisse soit visible, gouvernée et bancable.

## Ne pas dire

- « On est la tontine IA n°1 »
- « Agrément BCC »
- Qu’on remplace Mobile Money
