Format : 1 idée / slide · peu de texte · gros chiffres Fc.

### 1 — Titre
**e-AVEC**  
L’OS des associations villageoises d’épargne & crédit  
VUK’AFRIK 2026 · Village Finance / Fintech  
McBuleli · Kinshasa

### 2 — Problème
Dans une AVEC classique :
- Caisse **opaque** (cahier / cash)
- Risque de **détournement**
- Crédits **sans vote** traçable
- Pas d’**historique** pour une banque / FOGEC / ONG

→ L’épargne communautaire reste **invisible** pour le système financier.

### 3 — Solution
**e-AVEC** = même rituel AVEC, en numérique :
1. **Réunion** — parts 1–5 + solidarité (Fc)
2. **Caisse** — épargne, prêts, aide, clôture
3. **Gouvernance** — votes membres
4. **Passport** — historique portable + consentement partenaires

### 4 — Démo (live)
Ouvrir https://e-avec.org/demo

### 5 — Impact
- Transparence pour **chaque membre**
- Alertes **intégrité** pour gérants / ONG
- Passport → porte d’entrée crédit / formalisation
- Ancré RDC : pratique AVEC déjà connue

### 6 — Tech
- Prototype **live** (e-avec.org)
- Fc / Mobile Money (parcours terrain)
- Offline-aware (réseau faible Kinshasa)
- Facilitateur ONG (portefeuille multi-groupes)

- Upsell Passport / scoring vers institutions
